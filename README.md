# 🍽️ Basalt Bistro — Desktop UI Concept

A premium, high-fidelity restaurant landing page concept for an upscale bistro, built from scratch using HTML and CSS.

The project focuses on creating an elegant desktop dining experience through large-scale typography, structured layouts, imagery, asymmetrical design elements, CSS animations, and carefully controlled viewport proportions.

## ✨ Key Focus Areas

### 🖥️ Viewport-Proportionate Canvas Layout

Built primarily using `vw` and `vh` units to treat the desktop browser as a proportionally scaled visual canvas.

The layout is intentionally designed around desktop viewport proportions rather than fluid, mobile-first behavior.

### 🎨 Modern CSS Layouts

Uses modern CSS layout techniques including:

- **CSS Flexbox** for alignment and component positioning
- **CSS Grid** for structured multi-column layouts
- CSS positioning and transforms for asymmetrical design elements
- CSS transitions and animations for visual effects

### 📐 Intentional Design Constraints

This project was built explicitly as a **fixed desktop experience** to explore large-typography layouts, visual proportions, and asymmetrical compositions.

It is optimized for **desktop screen sizes of 1024px and above** and is not intended to be a fully responsive mobile/tablet website.
